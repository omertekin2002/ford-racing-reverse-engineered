Valid texture names:

Key:
	A = Contains alpha
	S = Alpha is only 0 or 255
	f = Texture is filtered
	M = Texture has mipmaps
	H = Texture is high quality (16bit) texture
	L = Texture is part of a livery set
	X = Texture is shadow texture
	! = Texture is 16 colour paletted texture
	$ = Texture is alpha-paletted on PS2
	# = Texture is NOT compressed using DX compression
